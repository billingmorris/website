# App Mayorista (website_mayorista) — Odoo 14.0 Community

Catálogo y toma de pedidos mobile-first para clientes mayoristas en `/mayorista`.

- Buscador en tiempo real por nombre, código interno o código de barras.
- Categorías del eCommerce (y subcategorías) como filtros.
- Destacados (campo "Destacado en App Mayorista" en el producto).
- Vista lista compacta (~4 productos por pantalla de celular) y vista galería.
- Precio según la lista de precios del cliente/website e inventario disponible (free_qty).
- Pedido con cantidades; total actualizado al instante.
- Confirmación a pantalla completa en móvil; el pedido queda como sale.order.

Configuración: Sitio web > Configuración > Sitios web > (sitio) > sección "App Mayorista".
